# Modern Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add subtle modern motion to the horizontal deck: swipe-linked transitions, word-reveal headings, card tilt and shine, magnetic controls, odometer stats, ambient blobs and a skills ticker.

**Architecture:** CSS does most of the work (`src/styles/motion.css`: scroll-driven animations, keyframes). Three small scripts (odometer arming in `StatCounter`, tilt and magnet in `Motion.astro`) use pure helpers from `src/lib/motion.ts`. Everything is gated by `prefers-reduced-motion: no-preference`, and tilt and magnet additionally by `(hover: hover) and (pointer: fine)`.

**Tech Stack:** Astro 7, TypeScript, CSS scroll-driven animations, Vitest + Container API, Playwright (port 4322).

**Spec:** `docs/superpowers/specs/2026-10-08-motion-design.md`

## Global Constraints

- No new dependencies. No layout or content changes to content components; they may only gain `data-tilt` / `data-magnet`.
- All motion is inside `@media (prefers-reduced-motion: no-preference)` (CSS) or behind `matchMedia('(prefers-reduced-motion: reduce)').matches === false` (JS). Under reduced motion, or with no JS, everything renders in its final state.
- Tilt max is 6° by default, and 2° where `data-tilt="2"`. Magnet max is 6px, within a 64px radius. Word stagger is 60ms. Odometer is 1.2s with a 70ms stagger. Blob opacity is ≤ 0.2 and blur 60px. The ticker loop is 30s.
- Only `transform`, `translate`, `scale`, `opacity` and `filter` are animated (no layout properties).
- Lighthouse mobile stays ≥ 90 in all four categories (target 100).
- Each commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Text directly on a tone with blobs behind it** (slide headings on yellow or mint): contrast must stay AA. Pinned by the Lighthouse `color-contrast` audit passing in Task 6.
2. **Clicking inside a tilted card** (a video poster or a post link) must still hit its target. Pinned by e2e `clicking a tilted video poster opens the modal` (Task 4).
3. **A settled slide** must show no residual exit effect (scale 1, opacity 1, no blur). Pinned by e2e `current slide content is crisp at rest` (Task 6).
4. **Word-split headings** keep their exact accessible name (no doubled or missing spaces). Pinned by e2e `split headings keep their names` (Task 2).
5. **Stats on a slide reached by deep link** (`/#slide-2`) must still end on the correct digits. Pinned by e2e `odometer ends correct after a deep link` (Task 3).

Running: `.odo--run .odo__strip { translate: 0 calc(var(--d) * -1em); transition: translate 1.2s cubic-bezier(.2,.8,.2,1) calc(var(--i) * 70ms) }`.

Script (replaces the count-up):

### Task 6: Swipe-linked slide transitions and final checks

**Files:** Modify `motion.css`; add cases to `tests/e2e/motion.spec.ts`

**Interfaces:** Spec §3.1:
```css
@supports (animation-timeline: view()) {
  @media (prefers-reduced-motion: no-preference) {
    .slide__inner { view-timeline: --slide inline; }
    .slide > .slide__inner { animation: slide-exit linear both; animation-timeline: view(inline); animation-range: exit 0% exit 100%; }
    .slide__head { animation: slide-enter-head linear both; animation-timeline: view(inline); animation-range: entry 0% entry 40%; }
    .slide__inner > :not(.slide__head) { animation: slide-enter-body linear both; animation-timeline: view(inline); animation-range: entry 0% entry 60%; }
  }
}
```
`slide-exit` animates to `scale .94; opacity .3; filter blur(4px)`, with the blur only inside `@media (min-width: 640px)`. The `slide-enter-*` animations go from `translate: 40px 0` / `80px 0`. Background wash: `.slide::before` with a right-edge gradient into the next slide's tone; each slide sets `--next-tone` by `nth-of-type`.

Note: the scroll-driven `animation` on `.slide__inner` and the cards must not override the existing reveal `animation` on `[data-reveal]` cards. Apply the enter-body animation to non-`[data-reveal]` wrappers only (grid containers and wrappers), not to the cards themselves.
